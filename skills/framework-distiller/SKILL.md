# 思维框架提炼规范

## Procedure（流程步骤）

1. 通读材料，识别其中有方法论价值的内容（"怎么想"而非"是什么"）
2. 对每个候选框架，按四要素组织：名称 / 核心观点 / 适用场景 / 来源
3. 校验：四要素缺一不可；金句摘抄、泛泛而谈不算框架，宁缺毋滥
4. 入库前检查是否与已有框架重复，重复则合并而非新增

## Specifications（完成标准）

- 每个框架卡片结构完整，能脱离原文独立理解
- core 字段必须说清"怎么想"——思考的动作与顺序，不是结论摘抄

## Advice（经验提醒）

- 一本书值得提炼的框架通常不超过 10 个，超过说明标准放得太宽
- 好的框架名称应该能当索引用（如"逆向思维""机会成本"），不要起"第三章心得"这类名字

## Forbidden Actions（禁止事项）

- 不要把全书摘要当作框架卡片
- 不要凭空补充原文没有的"框架"

## Required from User（需要用户提供）

- 喂养材料文件
- 是否允许将重要框架回写人格设定（默认需逐项确认）
